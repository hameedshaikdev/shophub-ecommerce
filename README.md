# 🛍️ ShopHub – E-Commerce Platform

A modern full-stack e-commerce web application built to transform a traditional family tailoring and textile business into a complete online shopping experience.

The platform allows customers to browse products, securely authenticate, manage their cart and wishlist, place orders, and make online payments through an intuitive and responsive interface.

---

## 🚀 Features

### Customer Features
- User Registration & Login
- Secure Authentication
- Browse Products by Category
- Advanced Product Search
- Product Detail Pages
- Shopping Cart
- Wishlist
- Checkout System
- Online Payment Integration
- Order History
- Responsive Design

### Admin Features

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/shophub-ecommerce.git
```

Navigate into the project

```bash
cd shophub-ecommerce
```

Install dependencies

```bash
npm install
```

Create a `.env` file and configure your environment variables.

Run the development server

```bash
npm run dev
```
